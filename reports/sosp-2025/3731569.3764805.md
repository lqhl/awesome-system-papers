# Spirit: Fair Allocation of Interdependent Resources in Remote Memory Systems

## 论文基本信息

- **标题**: Spirit: Fair Allocation of Interdependent Resources in Remote Memory Systems
- **作者**: Seung-seob Lee, Jachym Putta, Ziming Mao, Anurag Khandelwal (Yale University, UC Berkeley)
- **会议**: SOSP 2025
- **Session**: Data Channels
- **PDF**: 3731569.3764805.pdf

## 研究背景

远程内存系统（Remote Memory Systems）通过将服务器的内存容量扩展到其他服务器上，提升应用性能和内存利用率。其核心机制是：将热点数据缓存在本地 DRAM 中（Cache），将冷数据存储在远程内存中（通过 RDMA 网络访问）。这类系统在云环境中广泛应用，是内存解聚（Memory Disaggregation）领域的重要研究方向。

然而，多用户共享远程内存系统时，如何公平分配资源成为一个核心挑战。传统多资源分配方案如 DRF（Dominant Resource Fairness）假设：（1）不同资源类型之间相互独立；（2）应用对每种资源的需求是已知且固定的。这两个假设在基于 Cache 的远程内存系统中均不成立——Cache 大小与网络带宽之间存在复杂的应用相关依赖关系，且这种依赖在应用部署前通常是未知的。

具体而言，不同应用对 Cache 和带宽的敏感性差异巨大：STREAM 基准测试主要依赖网络带宽，增加 Cache 对其性能影响不大；Memcached 和 SocialNetwork 对 Cache 大小敏感，带宽需求随 Cache 增加而下降；DLRM 作为计算密集型深度学习推荐模型，对两者都不敏感。这种复杂的相互依赖关系使得简单的资源分配策略无法实现公平高效的资源利用。

## 要解决的问题

如何在多用户远程内存系统中，实现公平的资源分配，同时充分考虑 Cache 大小与网络带宽之间的复杂且应用相关的相互依赖关系？

## 核心贡献

- **Symbiosis 算法**：提出首个基于微观经济理论（CEEI - Competitive Equilibrium from Equal Incomes）的多资源公平分配算法，理论上可证明满足 Pareto 最优性、无嫉妒性（Envy-Freeness）和共享激励（Sharing Incentive）。
- **运行时依赖估计**：通过硬件辅助采样（Intel PEBS）和梯度下降回归方法，运行时估计每个应用的性能函数 $f_i(c, b)$，无需应用预先声明其资源需求。
- **透明实现**：基于现有的基于 Swap 的远程内存系统实现，无需修改应用或底层硬件，充分利用 Linux Swap 子系统。
- **性能验证**：在 Stream、Memcached、DLRM 和 SocialNetwork 四种真实应用上验证了 Spirit 的有效性，性能提升最高达 21.6%。

## 主要研究方法

论文首先分析了 Cache 与带宽之间相互依赖的应用特异性，揭示了现有 DRF 类方案的局限性。然后，论文将问题重新形式化：公平性的定义从"分配公平"转变为"性能公平"——每个应用通过相同的 Cache 和带宽份额应获得相等或更优的数据访问吞吐量。

基于这一重新形式化，Spirit 提出了基于竞价的 Symbiosis 算法。算法核心思想是：每个应用获得相同数量的"积分"（Credits），资源被赋予不同的价格，通过多轮竞价调整资源价格，直到市场出清（Market Clearing）。关键洞察是：竞标过程天然地让 Cache 敏感型应用用积分换取 Cache、带宽敏感型应用换取带宽，实现了资源的帕累托最优分配。

## 设计与实现

**系统架构**：Spirit 由两个核心组件构成——集中式资源分配器（Centralized Resource Allocator）和数据平面（Dataplane）。

**性能估计器**（§4）：Spirit 不依赖应用声明其资源需求，而是通过运行时测量估计每个应用的性能函数 $f_i(c, b)$。采用两阶段梯度下降回归方法：
- 第一阶段：通过 Intel PEBS 采样收集 LLC miss 直方图，构建访问频率分布 $g(x)$
- 第二阶段：考虑当前 Cache 大小下的实测 miss ratio，对参数进行微调

为减少搜索开销，Spirit 将搜索空间限制在当前分配附近（$\pm 5\epsilon$），因为估计误差在局部区域最小（< 10%）。

**Symbiosis 算法**（§3.2）：采用二元搜索确定资源价格。对于每个应用，在给定价格向量下求解：
$$\max_{c_i, b_i} f_i(c_i, b_i) \quad \text{s.t.} \quad p_c \cdot c_i + p_b \cdot b_i \leq 1/N$$
根据出清条件调整价格：若总 Cache 需求 > 1，增加 Cache 价格；若总带宽需求 > 1，增加带宽价格。算法可证明收敛到满足三个公平性性质的分配。

**实现**：采用基于 RDMA 的远程内存设置（类似 Hermes、Trirem等人工作），小量 DRAM 作为本地 Cache，通过 Linux Swap 设备经 RDMA over RoCE 访问远程内存。使用 Intel PEBS 采样 LLC misses 作为性能代理指标。

## 主要实验结果

**应用评估**（§6.1）：在 24 个应用实例场景下，Spirit 相比 uDRF 实现：
- Stream（带宽敏感）：吞吐量提升 21.6%
- Meta KVS（Cache 敏感）：吞吐量提升 5.9%，P99 延迟降低 16.8%
- SocialNetwork（混合敏感）：吞吐量提升 6.1%，P99 延迟降低 6.1%
- DLRM（计算密集）：不受影响（< 3% 变化）

**对比方案**：与 Harvest（基于短期运行时反馈的启发式方案）、Trade（应用间直接交易方案）和 Ideal（离线最优）对比，Spirit 在性能和公平性上均接近 Ideal，明显优于 Harvest 和 Trade。Trade 虽然利用了 $f_i$ 估计改善了部分性能，但损害了 SocialNetwork 的公平性。

**收敛时间**：Symbiosis 在 24 个应用场景下可在 1 秒内完成，平均每轮迭代约 140ms 收敛。使用单核平均开销 < 3.3%。在 1000 个应用时，执行时间仍在 20 秒以内。

**动态适应性**（§6.2）：当应用在运行时改变其资源敏感性（如 Stream 变为 Memcached 再变回 Stream），Spirit 能在约 10 分钟内检测到变化并重新收敛到稳定分配。

## 潜在问题 / 局限性

1. **竞拍机制非策略-proof**：竞拍类算法天然不是策略-proof 的，应用可能谎报其真实偏好。论文通过运行时测量 $f_i$ 来规避这一问题（应用无法操纵 PEBS 采样），但理论上若应用能通过访问模式操纵测量结果，则可能产生策略性行为。

2. **集中式架构的单点瓶颈**：集中式资源分配器负责所有应用的重新分配决策，在大规模部署中可能成为瓶颈。虽然论文声称 Symbiosis 可扩展到 1000 个应用，但未评估分配器的故障恢复和容错能力。

3. **性能估计精度依赖采样质量**：PEBS 采样的代表性直接影响 $f_i$ 估计精度。对于访问模式快速变化的应用，5 秒采样周期可能无法及时反映变化。

4. **仅支持两类资源**：Symbiosis 扩展到更多资源类型（如 CPU、内存容量、带宽）时的收敛性和效率未经验证。

5. **缺乏生产环境验证**：所有实验在受控实验室环境中进行，未与真实云服务商合作验证，也未评估在真实多租户混合负载下的表现。

6. **与 Spirit 相关工作的关系**：论文未与最新发表的类似工作（如 Cilantro、Karma）进行对比，也未讨论在 CXL 解聚内存等新架构上的适用性。

7. **SocialNetwork 的不公平性**：Trade 方案导致 SocialNetwork 性能下降的问题被简单提及但未深入分析，理想情况下不应存在这种情况。

## 个人评注

Spirit 的核心贡献在于将微观经济理论中的 CEEI 机制创造性地应用于多资源公平分配问题，并首次揭示了远程内存系统中 Cache 与带宽之间复杂的相互依赖性。这一问题的重新形式化——从"分配公平"到"性能公平"——具有重要的理论和实践意义。

从理论角度看，Symbiosis 算法有坚实的经济学基础支撑，能够同时满足 Pareto 最优性、无嫉妒性和共享激励三个性质，这本身就是一个有趣的理论结果。然而，竞拍机制与运行时测量相结合的方案设计虽然巧妙，但也引入了额外的复杂性——PEBS 采样的代表性、梯度下降的收敛速度、以及与分配 epoch 交互时可能产生的振荡等问题。

实验评估方面，论文涵盖了多种真实应用和对比方案，结果令人信服。但在评估规模上，24 个应用实例的配置相对保守，且缺乏与真实远程内存生产部署相关的验证。总体而言，Spirit 为远程内存系统的资源管理提供了一个新的理论框架和实用的解决方案思路。
