# R&D-Agent-Quant: A Multi-Agent Framework for Data-Centric Factors and Model Joint Optimization

## 一、基本信息

- **标题**：R&D-Agent-Quant: A Multi-Agent Framework for Data-Centric Factors and Model Joint Optimization
- **作者**：Yuante Li, Xu Yang, Xiao Yang, Minrui Xu, Xisen Wang, Weiqing Liu, Jiang Bian
- **机构**：Carnegie Mellon University, Microsoft Research Asia, HKUST, University of Oxford
- **源文件**：[2505.15155.pdf](../../papers/finance/2505.15155.pdf)
- **代码**：https://github.com/microsoft/RD-Agent

---

## 二、要解决的问题

量化投资研究流水线（因子挖掘 → 模型训练 → 回测评估）高度依赖人工干预，存在三个关键瓶颈：（1）**自动化不足**——假设生成、编码、调参需要大量人工迭代；（2）**可解释性差**——现有 LLM-based agent 直接从语言交互生成交易信号，缺少透明的因子构建逻辑；（3）**优化碎片化**——因子挖掘和模型训练各自为政，缺乏跨阶段反馈和联合优化。

---

## 三、洞察与设计

**关键洞察**：量化研究中因子（数据特征）和模型（预测架构）的质量高度耦合——好的因子能弥补简单模型的不足，好的模型能从噪声因子中提取信号。但传统流程将两者隔离优化，错失了联合提升的机会。通过 LLM 驱动的多 agent 协作框架，可以模拟人类量化研究员的"试错-反馈-改进"循环，实现因子和模型的自动化联合优化。

### 框架设计（五个 LLM-powered 单元）

1. **Specification Unit**：定义场景背景、数据接口、输出格式和回测机制，为下游模块提供统一约束。LLM 仅接触 schema 级信息，不接触原始市场数据，防止数据泄露。

2. **Synthesis Unit**：基于历史实验轨迹生成新假设。维护一个"知识森林"，根据过去实验的成功/失败反馈，自适应调整探索策略——成功则增加复杂度，失败则进行结构调整或引入新变量。

3. **Implementation Unit（Co-STEER Agent）**：将假设转化为可执行代码。具备知识库驱动的自我纠错能力——记录成功和失败的 task-code-feedback 三元组，遇到类似任务时检索历史解决方案。

4. **Validation Unit**：因子去重（IC 相关性 ≥ 0.99 则剔除）+ Qlib 回测平台验证。因子与当前最优模型配对评估，模型与当前最优因子集配对评估，保证评估的公平性。

5. **Analysis Unit**：多维度评估实验结果，生成定向改进建议。使用 **Multi-Armed Bandit（CLTS）调度器**决定下一轮优化因子还是模型。

---

## 四、主要贡献

1. 提出首个数据中心的多 agent 框架，实现因子-模型联合自动化优化。
2. 设计了完整的"研究-开发-反馈"闭环，包含 5 个 LLM-powered 功能单元。
3. 引入 Multi-Armed Bandit 调度策略（CLTS），自适应平衡因子优化和模型优化的资源分配。
4. 在 CSI300、CSI500、NASDAQ100 三个市场上验证，显著超越传统因子库和深度学习模型。

---

## 五、关键实验结果

### CSI300 主实验（2017-2020 测试期）

| 模型 | IC | ARR | IR (Sharpe) | MDD |
|------|-----|------|-------------|------|
| Alpha158 (因子库) | 0.0341 | 5.70% | 0.85 | -7.71% |
| Alpha360 (因子库) | 0.0420 | 4.38% | 0.67 | -7.21% |
| MASTER (SOTA 深度模型) | 0.0215 | 8.96% | 1.34 | -8.51% |
| **R&D-Agent(Q) o3-mini** | **0.0532** | **14.21%** | **1.74** | **-7.42%** |

- R&D-Factor 用仅 **22% 的因子数量**即达到 Alpha158 的 IC 水平，在 2019-2020 市场变化期保持稳定。
- R&D-Agent(Q) 年化收益比最优深度学习模型高约 2 倍。
- 在 CSI500 和 NASDAQ100 的 out-of-sample 测试（2024-2025）中同样表现最优，验证了泛化能力。

### Ablation：调度策略对比

Bandit 调度器在 IC、ARR 和 SOTA 选中次数上均优于纯因子优化、纯模型优化和随机调度。

## 六、局限性与未来工作

1. **依赖 LLM API 成本**：每轮迭代需要多次 LLM 调用，成本和延迟较高。
2. **因子可解释性仍有提升空间**：虽然比直接 LLM 交易信号更透明，但自动生成的因子仍需人工审查。
3. **市场适应性**：在不同市场（中美）上性能差异较大，NASDAQ100 上的 IC 整体偏低。
4. **单一评估框架**：仅使用 Qlib 回测，缺少对实盘滑点、流动性等因素的考量。

---

## 七、总结

R&D-Agent(Q) 是首个将量化投资全流程（因子挖掘 + 模型开发 + 回测评估）自动化的多 agent 框架。其核心创新在于通过 LLM 驱动的闭环迭代实现因子与模型的联合优化，用 Multi-Armed Bandit 调度器自适应分配优化资源。实验表明，该框架用更少的因子达到了更高的预测精度和交易收益，显著超越手工因子库和最优深度学习模型，且具备跨市场泛化能力。
