## 1. 研究背景与动机

AdamW 是 LLM 预训练的事实标准优化器，通过跟踪一阶动量（$m_t$）和二阶动量（$v_t$）实现学习率的自适应调整。然而，AdamW 的内存开销是模型参数量的 3 倍——对于 LLaMA-7B，每个参数需要存储 fp32 权重 + fp32 一阶动量 + fp32 二阶动量，总计约 84GB（仅 optimizer states）。

现有内存高效优化器面临三条路线各自的困境：
1. **GaLore/Fira**：使用 SVD 将梯度投影到低秩空间，避免全量 optimizer states，但 SVD 计算代价极高（Llama-7B 单次 subspace update ~10 分钟）
2. **Adam-mini**：移除一阶动量保留二阶动量，但仍有显著内存开销
3. **SGD**：内存极低但训练不稳定，性能明显落后于 AdamW

根本问题：能否设计一种优化器，同时实现 SGD 级的内存占用和 AdamW 级的训练质量？

## 2. 研究问题与核心挑战

核心问题：如何在利用 AdamW 的自适应学习率机制的同时，大幅降低其 optimizer state 的内存开销？

主要挑战：

1. **SVD 的计算瓶颈**：GaLore 依赖的 SVD 每 200 步需要 $O(mn^2)$ 的计算量，在大型矩阵上不可接受。

2. **Element-wise 自适应学习的结构化近似**：AdamW 的 element-wise 梯度缩放是否可以用更粗糙的粒度（channel-wise / tensor-wise）替代而不损失效果？

3. **低秩空间的随机投影 vs SVD**：SVD 是否必要？随机投影能否以更低开销达到类似效果？

4. **收敛保证**：粗粒度的学习率缩放在训练初期不稳定梯度上的表现需要理论支撑。

## 3. 主要贡献

1. **结构化学习率更新理论**：首次证明 AdamW 的 element-wise 梯度缩放可以粗粒度化为 channel-wise 甚至 tensor-wise 形式，且在 LLM 训练中仍保持有效性。

2. **APOLLO（Approximated Gradient Scaling）**：提出利用低秩辅助空间 + 纯随机投影来近似 channel-wise 梯度缩放因子的方法。APOLLO 相比 GaLore 所需秩更低（1/2），同时无需 SVD 计算。

3. **APOLLO-Mini**：将 tensor-wise 缩放进一步推到 rank-1 辅助空间，实现 SGD 级的内存占用，同时超越 AdamW 的训练质量。

4. **三项系统级突破**：
   - **3× 吞吐量提升**：在 8×A100-80GB 配置下，batch size 可扩大 4 倍，训练吞吐量提升 ~3×
   - **13B 单机训练**：首次在单张 A100-80G 上通过 naive DDP 预训练 LLaMA-13B
   - **7B 单卡 12GB 训练**：结合 INT8 权重量化，7B 模型预训练仅需 12GB 显存

5. **严格的理论保证**：基于 Johnson-Lindenstrauss 定理和随机矩阵理论，证明了 channel-wise 缩放在随机投影下的一致性边界。

## 4. 核心方法与设计

### 4.1 AdamW 的结构化粗粒化

AdamW 的 element-wise 梯度缩放因子 $S = \tilde{G}_t / G_t \in \mathbb{R}^{m \times n}$ 可以粗粒化为：

**Channel-wise**：$s_j = \frac{\|\tilde{G}_t[:, j]\|_2}{\|G_t[:, j]\|_2}$，每列共享一个缩放因子

**Tensor-wise**：$s = \frac{\|\tilde{G}_t\|_F}{\|G_t\|_F}$，整个矩阵共享一个缩放因子

实验验证：LLaMA-130M 上 channel-wise 与 element-wise 的最终困惑度相当（24.43 vs 25.08），甚至略优。引入 Norm-growth Limiter（梯度增长率限制器）解决训练初期不稳定梯度导致的 spike。

### 4.2 APOLLO 算法

```
Step 1: 计算梯度并投影到低秩空间
  G_t ∈ R^{m×n} ← -∇W φ_t(W_t)
  P_t ← N(0, 1/r)^{r×m}  (每 T 步重新采样)
  R_t ← P_t G_t ∈ R^{r×n}

Step 2: 在低秩空间维护 optimizer states
  M_t^R, V_t^R ← AdamW(R_t, β1, β2, λ=0)
  ~R_t ← M_t^R / √(V_t^R + ε)

Step 3: 计算 channel-wise 缩放因子
  s_j^R = ||~R_t[:, j]||_2 / ||R_t[:, j]||_2

Step 4: 在原始空间更新权重
  W_t ← W_{t-1} + η·α·G_t⊗S - η·λ·W_{t-1}
```

关键创新：
- 仅在 rank-r (r << n) 的投影空间中存储 optimizer states：内存从 $2mn$ 降至 $2rn$
- 纯随机投影替代 SVD，避免 $O(mn^2)$ 计算开销
- 每 T 步（默认 200）重新采样随机投影矩阵

### 4.3 APOLLO-Mini（Rank-1 极简版本）

进一步将 channel-wise 粗粒化到 tensor-wise：

$$s = \frac{\|\tilde{R}_t\|_F}{\|R_t\|_F}$$

设置 $\alpha = \sqrt{128}$ 补偿 rank-1 空间的信息损失。理论上证明：当 rank → 1 时，需要对梯度乘以 $\sqrt{n/r}$ 的补偿因子来维持与全秩 AdamW 一致的行为。

### 4.4 理论保证

**定理 4.1**（Channel-wise 一阶动量边界）：基于 JL 引理，给出了 $\|\tilde{M}_t[:, j]\|_2$ 与 $\|M_t[:, j]\|_2$ 之间的概率边界。

**定理 4.2**（Channel-wise 二阶动量边界）：给出了 $\|\tilde{V}_t[:, j]\|_1$ 与 $\|V_t[:, j]\|_1$ 之间的概率边界。

**更新比例边界**：最终证明 $\sqrt{n/r}$ 的缩放因子在概率意义上保证随机投影空间与原始空间行为的一致性。

## 5. 实现细节

与 DeepSpeed 集成，支持分布式数据并行（DDP）。结合 INT8 权重量化（来自 Zhang et al. 2024c）实现极致内存效率。

## 6. 实验结果

### 6.1 预训练质量（LLaMA-130M ~ 7B）

- **LLaMA-130M**：APOLLO (rank=1/4n) perplexity 24.43 vs AdamW 25.08（更优）
- **LLaMA-7B**：APOLLO 在验证困惑度上与 AdamW 持平，APOLLO-Mini 甚至略优
- **收敛稳定性**：APOLLO-Mini 在训练初期有轻微不稳定，但使用 gradient clipping 后收敛正常

### 6.2 系统效率

| 配置 | 优化器 | Batch Size | 吞吐量 | 内存 |
|------|-------|-----------|--------|------|
| 8×A100-80GB | AdamW | BS=8 | 1× | 高 |
| 8×A100-80GB | APOLLO | BS=16 | ~2.5× | ~50% |
| 8×A100-80GB | APOLLO-Mini | BS=32 | ~3× | ~25% |

### 6.3 极致内存效率

结合 Q-APOLLO-Mini（INT8 权重量化）：
- **LLaMA-7B 单卡 12GB**：首次在消费级 GPU 上实现 7B 模型预训练
- **LLaMA-13B naive DDP**：首次在单节点 8×A100-80GB 上无 ZeRO/gradient checkpointing 预训练

### 6.4 SVD vs 随机投影

在 LLaMA-350M 上，APOLLO + SVD 与 APOLLO + Random Projection 的性能几乎相同，但随机投影的计算开销可忽略（SVD 需要 ~10 分钟 vs 随机投影 ~毫秒）。

## 7. 潜在问题与局限性

1. **Norm-growth Limiter 的调参依赖**：APOLLO-Mini 在训练初期的不稳定性需要 gradient clipping 来缓解，clipping 阈值的选择缺乏理论指导。

2. **不同模型组件的差异处理**：并非所有 Transformer 层对粗粒度缩放同等敏感，论文缺少针对 attention QKV 与 FFN 分别调优的讨论。

3. **与混合精度训练的交互**：现代训练通常使用 BF16 精度，APOLLO 的更新精度（fp32 vs bf16）与 BF16 训练的兼容性需要注意。

4. **Fine-tuning 验证不充分**：论文重点在预训练，fine-tuning 场景（尤其是指令微调、RLHF 后训练）下的表现未被深入验证。

5. **Rank 自适应机制缺失**：不同训练阶段可能需要不同的投影秩，论文采用固定 T 步重采样，缺乏自适应调整机制。

## 9. 个人评注

APOLLO 是本届 MLSys 训练优化方向最有分量的论文之一。论文的核心洞察——"AdamW 的 element-wise 学习率缩放可以粗粒化为 channel-wise / tensor-wise 而不损失效果"——既简单又深刻，从理论上打通了两条原本独立的研究路线（GaLore 的低秩近似 + Adam-mini 的块级优化）。

从技术创新角度看，APOLLO 在 GaLore 的基础上实现了两个关键突破：（1）将所需秩降低一半（1/2 vs 1/4），（2）用随机投影完全替代 SVD，消除了制约 GaLore 实用性的计算瓶颈。APOLLO-Mini 的 rank-1 tensor-wise 缩放更是将 SGD 级内存效率与超越 AdamW 的训练质量结合，实现了理论上不可能的组合。

然而，论文在 26 页的巨大篇幅中（本次 MLSys 最长的论文），部分内容存在重复性描述（算法部分在正文中重复出现），且对 APOLLO-Mini 在极低秩下的理论解释（特别是补偿因子 $\alpha = \sqrt{128}$ 的选择依据）缺乏更直观的说明。此外，消融实验中对不同 rank 配置的效果分析可以更加详尽。

总体而言，这是近年来optimizer 内存优化方向最重要的进展之一，具有直接的系统实用价值和优雅的理论框架。
