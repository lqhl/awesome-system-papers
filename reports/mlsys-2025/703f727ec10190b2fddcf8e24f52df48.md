# Know Where You're Uncertain When Planning with Multimodal Foundation Models: A Formal Framework

**作者**：Neel P. Bhatt*, Yunhao Yang*, Rohan Siva, Daniel Milan, Ufuk Topcu, Zhangyang Wang（The University of Texas at Austin）
**会议**：MLSys 2025
**链接**：https://uncertainty-in-planning.github.io

## 一、背景

多模态基础模型（如 GPT-4、LLaVA）在机器人感知与规划中展现出巨大潜力，能够处理视觉输入并生成可执行的文本计划。然而，这些模型在实际部署中面临两类不确定性：**感知不确定性**（视觉理解的准确性）和**决策不确定性**（生成计划的正确性）。现有方法将模型视为黑箱，只提供聚合的不确定性度量，无法区分失败是来源于视觉感知错误还是规划决策缺陷，从而无法进行针对性的改进。

---

## 二、要解决的问题

1. **不确定性来源不可区分**：现有不确定性量化方法（如 log-likelihood）将感知与决策混为一体，当任务失败时无法定位根因——是看错了还是决策错了？
2. **依赖人工标注**：已有框架需要人工标注数据集来评估计划质量，限制了可扩展性和对动态环境的适应能力。
3. **缺乏形式化保证**：现有方法无法对生成的计划是否满足任务规范提供理论保证。

---

## 三、洞察与设计

**关键洞察**：多模态基础模型的感知模块和决策模块产生的不确定性本质不同——感知不确定性源于视觉编码器对物体识别的置信度，而决策不确定性源于语言生成器产出的计划是否满足时序逻辑规范。这两类不确定性可以被解耦，并分别用不同的数学工具（conformal prediction + formal verification）进行独立量化。

基于这一洞察，论文设计了一个三层框架：

1. **不确定性解耦**：将多模态模型拆分为视觉编码器 V 和文本生成器两部分，分别量化各自的不确定性。
2. **感知不确定性量化**：通过 conformal prediction 校准视觉编码器的 softmax 置信度，得到具有统计保证的感知不确定性分数 $u_p$（Definition 1）。具体做法是学习一个 projection head H，将图像嵌入映射到物体类别置信度空间，利用校准集构建 nonconformity 分布，再将置信度转化为有理论下界的不确定性分数。
3. **决策不确定性量化**：提出 Formal-Methods-Driven Prediction (FMDP)，将文本计划通过语义解析转换为 Kripke 结构（自动机），然后用 model checking 验证该结构是否满足预定义的时序逻辑规范（如 □(red_light → ¬move_forward)）。结合 conformal prediction 框架，得到决策不确定性分数 $u_d$（Definition 2）。

## 四、实现细节

### 感知不确定性校准

- 使用 CLIP-L-336px 视觉编码器 + 预训练 projection head 进行物体分类
- 校准集：542 张 Carla 模拟器图像，3000 个物体标注
- 通过 conformal prediction 将 softmax 分数校准为具有 $(1-\epsilon)$ 概率保证的不确定性分数

### FMDP 决策不确定性

- **Algorithm 1 (NL→Kripke)**：将文本指令解析为动词/名词短语序列，构建线性 Kripke 结构，初始状态标签为图像中观测到的物体集合
- 使用 NuSMV 等 model checker 验证 Kripke 结构是否满足时序逻辑规范
- 校准集：400 张 Carla 图像，10 条安全关键逻辑规范
- 离线构建 nonconformity 分布，在线通过 Eq. 8 在 O(1) 时间内估计决策不确定性

### 两种干预机制

- **Active Sensing**：当 $u_p < t_p$（阈值 0.7）时，触发机器人重新观测（旋转摄像头、切换视角、等待后重拍），直到感知不确定性满足阈值
- **Automated Refinement（Algorithm 2）**：自动生成高质量微调数据——过滤高感知不确定性图像，仅保留通过 formal verification 的计划作为训练样本，对 LLaVA 的文本生成器进行 supervised fine-tuning（也支持 DPO）

### 模型

- 基础模型：LLaVA-1.5-7B（CLIP-L-336px + Vicuna-7B-v1.5）
- 训练数据：800 张 Carla 模拟器图像

## 五、实验结果

### 实验平台

- **模拟环境**：Carla 自动驾驶模拟器
- **真实环境**：地面机器人 + NuScenes 数据集
- **测试集**：50 个驾驶场景

### 主要结果

| Planning Pipeline | 平均感知不确定性分数 | 平均决策不确定性分数 | 规范满足概率 (Avg) | 规范满足概率 (SD) |
|---|---|---|---|---|
| Raw Model w/o AS | 0.842 | 0.279 | — | — |
| Raw Model with AS | 0.936 | 0.306 | 0.316 | 0.180 |
| Fine-tuned (Benchmark) with AS | 0.936 | 0.931 | 0.933 | 0.048 |
| **Fine-tuned (Ours) with AS** | **0.936** | **0.955** | **0.959** | **0.025** |

### 关键数字

- Active sensing 将感知不确定性提升 >10%，决策不确定性随之提升 10%
- 模拟数据上决策不确定性降低 35%
- Fine-tuning 后规范满足概率提升 >50%（从 0.316 到 0.959）
- 相比 benchmark，规范满足概率提升 ~5%，标准差降低 ~40%
- 设置 $t_d = 0.7$ 后，规范违反率从 8% 降至 0%
- Sim2Real 迁移：仅用模拟数据训练，在真实环境达到 >95% 规范满足率

## 六、批判性分析

1. **实验规模偏小**：测试集仅 50 个场景，训练集 800 张图像，校准集 542/400 张。这样的规模下得到的 "5% 提升" 和 "40% SD 降低" 统计显著性存疑。作者未报告置信区间或 p-value。

2. **任务场景过于简单**：自动驾驶任务限于 {直行、左转、右转、掉头} × {红绿灯、停车标志}，仅 10 条逻辑规范。真实自动驾驶场景的复杂度远超于此（多车交互、非结构化道路、天气变化等），框架是否能扩展到更复杂的规范集未经验证。

3. **Kripke 结构构建的局限性**：Algorithm 1 将文本指令线性解析为状态序列，这一假设对于复杂的、包含条件分支的计划明显不足。作者承认原子命题数量增长时计算复杂度指数增长，但对如何处理真实场景中几十到几百个原子命题未做讨论。

4. **感知不确定性量化依赖 CLIP**：使用 CLIP 做物体识别的置信度作为感知不确定性的代理，但 CLIP 的分类能力远不如专用目标检测模型（如 YOLO、DETR）。conformal prediction 的保证建立在校准集与测试集同分布假设上（Assumption 1），Sim2Real 场景下该假设是否成立值得质疑。

5. **"5% 提升" 的实际意义**：相对于 benchmark 的核心贡献是过滤高感知不确定性数据来改善训练集质量，这本质上是一种数据清洗策略。将此包装为 "不确定性解耦框架" 可能过度宣称了方法的贡献。

6. **Active Sensing 的实用性**：论文假设机器人可以通过旋转摄像头或等待来降低感知不确定性，但未讨论重新观测的次数上限和时间成本。在时间敏感的自动驾驶场景中，反复重拍可能不现实。

---

## 七、AI Infra / MLSys 视角

1. **不确定性解耦思想的迁移价值**：在 LLM serving 系统中，也存在类似的 "输入理解不确定性" 和 "生成质量不确定性" 的解耦问题。例如，多模态推理系统可以在视觉编码阶段就判断输入质量，在质量不足时请求更高分辨率输入或触发 fallback 策略，而非等到生成完成后才发现错误。

2. **Formal verification 作为自动化训练数据筛选**：论文的 automated refinement 思路——用形式化验证自动筛选合格的训练样本——可以推广到 LLM alignment 场景。对于有明确规范的任务（如代码生成、数学推理），可以用 formal methods 替代人工标注来自动构建 preference data。

3. **在线推理时的不确定性阈值控制**：框架中 $u_d \geq t_d$ 才执行计划的思路，类似于 LLM 推理中的 speculative decoding 验证机制——生成后验证、不合格则拒绝。这种 "生成-验证-执行" 的 pipeline 设计对安全关键的 AI agent 系统有参考价值。

4. **可跟进的研究方向**：
   - 将 FMDP 扩展到更复杂的 LLM agent 场景（如 tool-calling、multi-step reasoning），用 formal verification 量化 agent 行动计划的可靠性
   - 探索 conformal prediction 在 LLM serving 中的应用：根据不确定性分数动态路由到不同规模的模型（uncertainty-aware model routing）

---

## 八、总结

本文提出了一个将多模态基础模型中的感知不确定性和决策不确定性进行解耦、量化和缓解的形式化框架。通过 conformal prediction 校准感知置信度，通过 FMDP 结合时序逻辑验证量化决策不确定性，并设计了 active sensing 和 automated refinement 两种干预机制。在 Carla 模拟和真实机器人驾驶任务上，框架将规范满足概率提升至 95.9%，标准差降低 40%。主要局限在于实验规模小、任务场景简单、Kripke 结构线性假设限制了对复杂计划的表达能力。框架的核心价值在于 "分而治之" 处理不确定性的思想，对安全关键的机器人和 AI agent 系统有参考意义。
