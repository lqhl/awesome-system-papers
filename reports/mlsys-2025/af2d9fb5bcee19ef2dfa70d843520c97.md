## 一、背景

大语言模型（LLM）在 NLP 领域取得了巨大进展，但其部署需要大量计算和内存资源。随着模型规模不断增长，模型压缩技术成为平衡质量与效率的关键手段。结构化剪枝（structured pruning）通过移除模型中不太关键的组件来降低复杂度，是一种有前景的策略。近期研究发现，Transformer 中间层存在显著冗余——移除这些层对整体模型质量影响很小（Men et al., 2024; Gromov et al., 2024），residual stream 只被非关键层的输出轻微修改。

然而，剪枝后的质量恢复仍是核心挑战：标准的 supervised fine-tuning（SFT）虽然能部分恢复质量，但会引入 catastrophic forgetting，使模型丧失原有的通用能力。

---

## 二、要解决的问题

1. **One-shot 结构化剪枝的质量下降**：直接移除 Transformer 的 decoder block 后，模型在需要多步推理的任务（如 ARC-C、GSM8k）上质量严重退化。例如 Llama 3.1-8B Instruct 剪去 6 层后，GSM8k 准确率从 75.59% 骤降到 1.29%。

2. **SFT 引发的灾难性遗忘**：用任务特定数据做 fine-tuning 时，模型会偏离原始训练分布，导致在 fine-tuning 数据未覆盖的任务上丧失已学能力。传统的缓解策略（data replay、parameter importance）在 LLM 规模下不实用。

3. **剪枝 + SFT 的双重退化**：剪枝破坏了层间信息流，SFT 又引入分布偏移，两者叠加使得质量恢复更加困难。

---

## 三、洞察与设计

**关键洞察**：用原始未剪枝模型对 fine-tuning 数据集进行重写（rewrite），可以生成语义等价但分布对齐的训练数据，从而在 fine-tuning 时同时保持任务正确性和与原始模型知识分布的一致性，避免分布偏移带来的灾难性遗忘。

基于这一洞察，论文提出 **Self-Data Distilled Fine-Tuning** 方法，分为三步：

1. **Layer Pruning**：使用 angular cosine distance 度量层间激活相似度，找到冗余最大（即输出最相似）的连续 n 层 block 一次性移除。具体地，对每个候选起始层 ℓ，计算 ℓ 与 ℓ+n 层最后 token 位置激活向量的 angular cosine distance，选取距离最小的 block 剪除。

2. **Self-Data Distillation**：用原始未剪枝模型 M 对 fine-tuning 数据集中的每条样本生成 distilled output ỹ。生成方式是将原始 input x、context c 和原始 response y 一起作为 prompt 输入 M，让 M 重写 response。通过条件筛选（Extract(ỹ) = y_t）确保关键信息（如数学推理的最终答案）不丢失。

3. **Fine-Tuning on Distilled Data**：用 distilled 数据集对剪枝后的模型做 SFT，优化目标为 L_Self-DataFT(θ') = -log f_θ'(ỹ₀ | c_t, x_t)。

4. **Model Merging（可选）**：对不同数据集上 self-data distilled 的模型，用 SLERP 插值合并，综合互补知识进一步提升质量。

---

## 四、实现细节

- **剪枝指标**：Angular cosine distance 只在最后一个 token 位置计算 cosine similarity，相比 Block Influence（BI）对整个 sequence 计算，效率更高且效果相当。使用 RedPajama 作为代表性数据集评估层间距离。

- **Fine-tuning 配置**：使用 LoRA 做参数高效微调。评估数据集包括 GSM8k（数学推理）、OpenMathInstruct 50k（数学+推理）、Dolly（对话）、Alpaca（指令跟随）。

- **条件筛选机制**：distilled output 必须通过 Extract 函数验证，确保结构化任务（如数学题）的答案正确性。若 distilled output 的答案不匹配原始答案，则回退使用原始 response。

- **Model Merging**：SLERP 沿高维球面最短路径插值两个模型参数，用于合并 OpenMathInstruct 和 Alpaca 上分别 self-data distilled 的模型。

- **Speculative Decoding 集成**：将 self-data distilled 的剪枝模型作为 draft model，配合 70B/123B 的 target model 做 speculative decoding，每步生成 6 个 speculative token + 1 个 base token。

- **评估**：主要在 HuggingFace Open LLM Leaderboard v1 的 6 个 benchmark 上评估：ARC-C (25-shot)、HellaSwag (10-shot)、TruthfulQA (0-shot)、MMLU (5-shot)、Winogrande (5-shot)、GSM8k (5-shot)。

## 六、批判性分析

1. **SFT 基线不公平**：论文中 SFT 用原始数据集训练，self-data distillation 用原始模型 rewrite 后的数据集训练——这不是唯一的变量。原始未剪枝模型的 rewrite 过程本质上是 teacher-student distillation 的一种形式（teacher = 原始模型，student = 剪枝模型），而 SFT 基线完全没有引入任何 teacher 信号。更公平的基线应该是标准 KD（用 teacher logits 做蒸馏），而非纯 SFT。

2. **"Self-Data Distillation" 命名有误导性**：论文声称这是"self"蒸馏，但实际上是用一个更大/更强的模型（未剪枝原始模型）生成训练数据给一个更小的模型（剪枝后模型）。这本质上就是 knowledge distillation，只是蒸馏发生在数据层面而非 logit 层面。称其为"self"暗示不需要额外模型，但实际上需要完整的原始模型做推理生成。

3. **Block Size=2 时 self-data distillation 反而比 No FT 差**：Table 1 中 Block Size=2 时，No FT 达 95.41% recovery，而 self-data distillation 只有 94.37%。这说明轻度剪枝时，fine-tuning 反而引入了不必要的扰动，但论文对此未作讨论。

4. **评估 benchmark 过于集中且过时**：全部基于 Open LLM Leaderboard v1（已被 v2 替代），且 6 个 benchmark 中有多个已被认为区分度不足。缺少更现代的评估（如 MMLU-Pro、IFEval）和实际生成质量评估（如人工评估、MT-Bench 打分）。

5. **Speculative decoding 缺少端到端 latency 数据**：论文只报告了 accepted length 这一中间指标，但未给出在实际硬件上的端到端推理延迟和吞吐量。accepted length 的提升不一定直接转化为等比例的延迟降低。

6. **Mistral 模型上的提升幅度明显更小**：在 Mistral-7B 上，self-data distillation 相比 SFT 的提升只有 2-5 个百分点，远小于 Llama 上的 8-12 个百分点。论文未深入分析为什么方法的有效性高度依赖基础模型架构。

7. **数据生成成本被忽略**：Self-data distillation 需要用完整原始模型对整个 fine-tuning 数据集做推理生成，这一步的计算成本没有被量化。对于大规模数据集或更大的原始模型，这一成本可能不容忽视。

## 七、AI Infra / MLSys 视角

1. **Data-level distillation 作为模型压缩的通用后处理**：论文展示了通过调整训练数据分布（而非修改训练算法或添加辅助 loss）来恢复压缩模型质量的可行性。这个范式可以推广到量化、稀疏化等其他压缩技术的 fine-tuning recovery 场景，且对训练框架的侵入性极低。

2. **Speculative decoding 的 draft model 优化方向**：论文发现 self-data distilled 的剪枝模型作为 draft model 能显著提升 acceptance rate。这启发了一个研究方向：**系统化地为 speculative decoding 定制 draft model**，而非简单使用现有小模型。具体可以探索：(a) 针对 target model 特定的输出分布做数据蒸馏；(b) 联合优化 draft model 的大小和 acceptance rate 以最大化端到端吞吐。

3. **与 training-time pruning 的对比缺失**：当前方法是 post-training pruning + fine-tuning recovery，而 training-time pruning（如 Sheared LLaMA 的 targeted structured pruning during pre-training）可能是更优的路线。值得研究两种范式在相同计算预算下的质量-效率 Pareto 前沿对比。

4. **可操作的 follow-up**：将 self-data distillation 与 logit-level KD 结合，用原始模型的 output distribution 同时在 data level 和 logit level 指导剪枝模型 recovery，预期能进一步缩小与原始模型的质量差距。

---

## 八、总结

本文提出 self-data distilled fine-tuning，利用未剪枝的原始 LLM 重写 fine-tuning 数据集，使剪枝后模型在 fine-tuning 时保持与原始模型知识分布的对齐，有效缓解 SFT 带来的灾难性遗忘。在 Llama 3.1-8B Instruct 上剪除 6 层（16.3% FLOPs 节省）时，方法保留 91.2% 原始质量（vs SFT 的 81.7%），并在 speculative decoding 场景下显著提升 token acceptance rate。方法简单实用，但本质上是一种数据层面的 knowledge distillation，需要完整原始模型做推理生成，且在不同基础模型上效果差异较大。
