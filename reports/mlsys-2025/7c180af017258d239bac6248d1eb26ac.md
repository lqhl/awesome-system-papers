## 1. 研究背景与动机

混合模型（Hybrid Models）结合了注意力层（Attention Layers）的语言建模能力和状态空间模型（State Space Models, SSMs，如 Mamba）的效率，在支持长上下文的同时保持了次二次方（sub-quadratic）的计算复杂度。混合模型在工业界的应用越来越广泛。

然而，混合模型给前缀缓存（Prefix Caching）带来了独特挑战。前缀缓存是 LLM 推理中跳过冗余计算的关键优化技术，其核心思想是复用多个请求之间的共享前缀。

**混合模型带来的问题**:
1. **原地状态更新（In-place State Updates）**: SSM 层会递归更新内部状态，无法像 KV Cache 那样直接回滚和复用。
2. **状态存储开销**: SSM 的隐藏状态（Hidden State）大小与序列长度成正比，远大于单个 token 的 KV 缓存。
3. **FLOP 效率差异**: SSM 层和 Attention 层的 FLOP 效率差异巨大（SSM 层的 FLOP 节省量与序列长度成正比），缓存驱逐策略必须考虑这一差异。

## 2. 研究问题与核心挑战

**核心问题**: 如何为混合模型设计高效的前缀缓存机制，同时处理 SSM 状态的可变性和不同层类型的 FLOP 效率差异？

**具体挑战**:
1. **SSM 状态的可变长度**: SSM 状态包含对所有历史 token 的压缩表示，无法像 KV 一样按 token 粒度管理。
2. **检查点策略（Checkpointing）**: 如何选择检查点位置以平衡缓存粒度和计算开销。
3. **FLOP 感知的缓存驱逐**: 不同 radix 节点的 FLOP 效率差异巨大，简单的 LRU 策略不是最优的。

## 3. 主要贡献

1. **Chunked State Passing**: 提出将 SSM 状态分割成多个块（chunks），支持部分状态的复用和缓存。
2. **两段预填充（Two-Pass Prefill）**: 对于不支持 chunked state passing 的模型，通过两段预填充获得精确的前缀状态。
3. **FLOP 感知驱逐策略**: 提出基于 FLOP 效率的 Utility Score，平衡缓存命中率和 FLOP 节省量。
4. **与现有系统集成**: Marconi 可与 vLLM 和 SGLang 等主流推理系统集成。

## 4. 核心方法与设计

### 4.1 混合模型的 Prefix Caching 挑战

在传统 Transformer 中，KV Cache 可以独立地存储和复用。但 SSM 的隐藏状态是累积的：
- KV Cache: 存储每个位置的 key 和 value 向量
- SSM State: 存储一个压缩的隐藏状态向量

```
SSM 层执行:
  h_t = A * h_{t-1} + B * x_t
  y_t = C * h_t
```

### 4.2 Chunked State Passing

Marconi 将 SSM 状态按固定间隔（如每 64 个 token）分割成块：

```
序列: [token_0, token_1, ..., token_79]
状态块: [state_at_64, state_at_80]
```

这样，新请求可以从检查点状态开始计算，而不是从头开始。

### 4.3 两段预填充

对于不支持 chunked state passing 的模型（如 Mamba-2）：
1. 第一段：预填充前 80 个 token，获得前缀状态
2. 第二段：从前缀状态开始，继续预填充剩余 token

### 4.4 FLOP 感知驱逐策略

Marconi 提出了考虑 FLOP 效率的 Utility Score：

```
S(n) = recency(n) + α * flop_efficiency(n)
```

其中 `flop_efficiency` 反映了缓存该节点能节省的 FLOP 量：
- SSM 层：flop_efficiency 随序列长度线性增长
- Attention 层：flop_efficiency 恒定

### 4.5 Token Block 与 State Block

Marconi 维护两类 radix tree 节点：
- **Token Block**: 存储 KV Cache
- **State Block**: 存储 SSM State Chunks

## 5. 实验结果

### 5.1 Token 命中率

在 LMSys、ShareGPT 和 SWEBench 数据集上的实验：
- Marconi 在各种缓存大小下均显著优于 vLLM+ 和 SGLang+
- 在长序列场景（如 SWEBench）下，Marconi 的优势更为明显

### 5.2 TTFT 提升

P95 TTFT（Time to First Token）相比 Vanilla Inference 的相对提升：
- LMSys: 约 0.7x（降低 30%）
- SWEBench: 约 0.6x（降低 40%）

### 5.3 缓存竞争分析

在不同缓存大小下的实验表明，FLOP 感知驱逐策略在中等缓存竞争情况下收益最大。

### 5.4 变化层组合的影响

在不同 SSM/Attention 层比例配置下的实验验证了 Marconi 对各种混合模型架构的适应性。

## 6. 潜在问题与局限性

1. **检查点间隔的选择**: 论文没有深入讨论如何选择最优的检查点间隔，这可能需要根据具体模型和硬件特性调优。
2. **两段预填充的开销**: 两段预填充方案虽然精确，但增加了额外的计算开销。
3. **与 PagedAttention 的集成**: Marconi 对 PagedAttention 等现有优化技术的兼容性还需要进一步验证。

## 7. 未来工作

1. 探索 SSM 状态的自适应压缩
2. 结合 KV Cache 压缩技术
3. 在更大规模的混合模型上进行评估

## 8. 个人评注

Marconi 针对的是一个非常实际的问题：随着 Mamba、Mamba-2 等 SSM 模型和 xLSTM 等混合模型的兴起，如何将这些新架构与现有的推理优化技术（如前缀缓存）结合是一个重要课题。

论文的核心贡献在于识别了 SSM 状态与 KV Cache 的本质差异，并提出了相应的解决方案。特别是 FLOP 感知驱逐策略，体现了对推理系统中计算与内存权衡的深入理解。

论文的实验设计也比较完善，覆盖了多种数据集和模型配置。不过，论文主要关注的是前缀缓存这一个环节，没有讨论混合模型推理中的其他优化机会（如注意力计算与 SSM 计算的调度优化）。

作为一个相对新兴的研究方向，混合模型的前缀缓存还有很多开放问题值得探索。
