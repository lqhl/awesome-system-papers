# BOUTE: Cost-Efficient LLM Serving with Heterogeneous LLMs and GPUs via Multi-Objective Bayesian Optimization

**作者**：Youhe Jiang (University of Cambridge), Fangcheng Fu (Shanghai Jiao Tong University), Eiko Yoneki (University of Cambridge)
**会议**：MLSys 2026
**链接**：[arXiv:2062.10927](https://arxiv.org/abs/2062.10927)
**源文件**：[[d9d4f495e875a2e075a1a4a6e1b9770f.pdf]]

---

## 一、背景

LLM 部署成本高昂，服务提供商面临在响应延迟、输出质量和 GPU 成本之间取得平衡的挑战。当前降低成本的两条主流路径：（1）**异构模型路由**（algorithmic perspective）——将简单查询路由到小模型、复杂查询路由到大模型；（2）**异构 GPU 部署**（systems perspective）——利用不同类型 GPU（如 RTX 5090 + H100）替代全用高端 GPU 的同构方案。然而，这两个维度长期被独立优化，缺乏 algorithm-system co-design。

---

## 二、要解决的问题

1. **路由与部署的循环依赖**：最优路由策略依赖于各模型在具体 GPU 部署下的延迟特性，而最优部署方案又依赖于路由决定的负载分布。二者孤立优化导致全局次优。
2. **异构资源分配的组合爆炸**：不同 GPU 类型 × 不同模型 × 不同并行策略（TP/PP/DP）的组合空间巨大，穷举搜索不可行。
3. **多目标权衡**：延迟与质量之间存在天然冲突——将更多查询路由到大模型提高质量但增加延迟，反之则降低质量。需要在给定预算约束下找到 Pareto 最优解。

---

## 三、洞察与设计

**关键洞察**：不同模型在不同 GPU 类型上表现出截然不同的性价比特征——小模型（如 Llama3.1-8B）在 RTX 5090 上比 H100 快 1.5×，而大模型（如 Llama3.1-70B）在 H100 上比 RTX 5090 快 2×。因此异构 GPU 部署与异构模型路由天然互补：路由利用模型多样性平衡延迟和质量，部署利用 GPU 多样性优化每个模型的性价比，二者协同可显著提升整体 serving 成本效率。

基于此洞察，BOUTE 将路由策略和部署配置统一建模为一个约束多目标优化问题，并设计了 Multi-Objective Bayesian Optimization（MOBO）框架联合求解：

- **离线准备阶段**：通过模拟器构建性能数据库，枚举不同模型在不同 GPU 上的各种并行配置（TP/PP/DP），记录 ⟨部署配置, 系统负载⟩→ 系统延迟的映射关系
- **在线优化阶段**：以路由阈值 τ 和部署选择 c 为决策变量，用 Gaussian Process 代理模型拟合延迟和质量目标，通过 qNEHVI acquisition function 迭代搜索 Pareto 最优解

## 四、实现细节

**推理任务模拟器**：基于 ETH EASL Scratchpad 模拟器，支持 continuous batching、区分 prefill（compute-bound）和 decoding（memory-bound）阶段特性。输入包括 GPU 特性 profile 和子采样工作负载 trace。

**两阶段模拟**：
- **Stage 1（模型并行）**：对每个模型类型和 GPU 类型，枚举所有合法的 TP/PP 组合，模拟不同系统负载下的延迟。通过剪枝规则（显存不足、TP 限制在机内互联）减少搜索空间
- **Stage 2（数据并行）**：在模型并行基础上，模拟多副本 DP 部署，通过负载分布搜索找到最小化最大副本延迟的分配方案

**部署候选生成**：
- 同构候选：每种 GPU 类型上对同构配置做 Pareto-skimming（延迟-成本空间），保留 10-20 个候选
- 异构候选：枚举中间预算点，对每个预算用 multiple-choice knapsack 问题从不同 GPU 类型的同构候选中组合

**MOBO 内核设计**：
- ARD Matérn-5/2 核处理路由特征（平滑连续效果）
- ARD Matérn-3/2 核处理部署特征（粗糙阶跃转换）
- Product Kernel 捕捉路由-部署交互效应
- 自定义 PreferenceWeightedKernel 注入 model-to-GPU 分配先验
- 基于 GPyTorch + BoTorch 实现，使用 Log+Standardize（延迟）和 Logit+Standardize（质量）做目标变换

**任务协调器**：基于 libP2P 建立 P2P 网络连接，三步路由流程——router 评估查询难度 → 协调器根据负载分布选副本 → 分发执行。

## 五、实验结果

**实验平台**：异构 GPU 集群，包含 H100、A100、L40S、RTX 5090 等 GPU 类型。

**基线**：Stand-Alone（单模型部署）、RouteLLM（仅路由优化）、BOUTE-Homo（BOUTE 仅使用同构 GPU）。

**主要模型**：Llama3.1-8B + Llama3.1-70B，评测数据集包括 GSM8K、MMLU、MT-bench。

| 指标 | 对比对象 | 提升幅度 |
|------|---------|---------|
| 系统延迟（相同预算+质量） | vs Stand-Alone | 最高 2.57×，平均 1.58× |
| 系统延迟（相同预算+质量） | vs RouteLLM | 最高 2.07×，平均 1.59× |
| 成本节省（相同延迟+质量） | vs Stand-Alone | 平均 39.7% |
| 成本节省（相同延迟+质量） | vs RouteLLM | 平均 38.0% |
| 成本节省（相同延迟+质量） | vs BOUTE-Homo | 平均 15.0% |

**模拟器精度**：在 Llama3-70B 上不同并行配置的吞吐量估计误差在 2%-7% 之间。

**MOBO 收敛**：约 50 次迭代后收敛，Hypervolume 在 30-50 次迭代内趋于稳定。

## 六、批判性分析

1. **GPU 类型多样性有限**：实验主要围绕 H100 和 RTX 5090 两种 GPU 展开，虽提及 A100 和 L40S，但异构组合的多样性验证不足。实际生产环境中 GPU 类型更多且跨代差异更大，MOBO 的搜索效率是否仍能保持存疑。

2. **模型组合过于简单**：核心实验基本限于 8B + 70B 两个模型的路由。实际生产中可能有 3-5 个不同规模的模型（如 1B/8B/70B/405B），模型数量增加后搜索空间和 GP 代理模型的拟合质量如何变化未做充分讨论。

3. **离线模拟器假设较强**：模拟器基于 profiled 的 GPU 特性和固定的工作负载 trace，但生产环境中查询分布会随时间漂移。论文未讨论模拟器 profile 的时效性以及何时需要重新运行离线阶段。

4. **路由质量评估依赖子采样**：路由策略的质量估计基于子采样 trace，但不同子采样可能导致质量估计方差较大，论文未分析这一不确定性对最终 Pareto 前沿的影响。

5. **端到端开销未充分报告**：离线阶段称"数十分钟完成"，但未报告在线 MOBO 优化的耗时和计算资源需求。对于需要频繁调整配置的场景（如弹性伸缩），这一开销可能成为瓶颈。

6. **成本模型过于简化**：仅考虑 GPU 租用成本（$/h），未计入网络带宽、存储、路由器推理成本等实际运维开销，可能高估了异构部署的成本优势。

## 七、AI Infra / MLSys 视角

**对 AI 系统研究的启发**：

1. **Algorithm-system co-design 的范式价值**：BOUTE 展示了将算法决策（路由）与系统决策（部署）统一优化的收益。这一思路可推广到其他场景——如 speculative decoding 中 draft model 和 target model 的异构部署、MoE 模型中 expert 的跨 GPU 放置策略。

2. **Bayesian Optimization 在系统配置中的应用**：用 MOBO 处理系统多目标优化是一个值得借鉴的方法论。未来可扩展到训练场景（如并行策略搜索、batch size 与学习率联合优化）或更复杂的推理管线配置（如 KV cache 管理策略搜索）。

3. **异构集群调度的实际需求**：随着 GPU 代际更替加速（H100→B200→下一代），生产集群必然长期处于异构状态。BOUTE 的 model-to-GPU 匹配思路有实际落地价值。

**可跟进的研究方向**：

- **动态在线适应**：将离线 MOBO 扩展为在线 bandit 或 online BO，支持工作负载漂移时的实时策略调整
- **与 disaggregated serving 结合**：在 prefill-decode 分离架构（如 DistServe）中引入异构 GPU 分配和路由协同优化
- **多租户场景**：多个 LLM 服务共享异构 GPU 池时的全局调度优化
- **推理成本感知的 cascading**：将 BOUTE 的路由机制与 speculative decoding、early exit 等推理加速技术结合

---

## 八、总结

BOUTE 提出了一个联合优化 LLM 路由策略和异构 GPU 部署配置的系统，核心是用 Multi-Objective Bayesian Optimization 框架打破路由与部署之间的循环依赖，在给定成本预算和质量要求下找到 Pareto 最优的延迟-质量权衡。实验表明相比现有方案可降低 15%-61% 的成本或将延迟降低至 1/2.57。主要局限在于实验规模较小（2 个模型、2 种主要 GPU 类型）、离线模拟器对动态负载的适应能力未验证，以及成本模型较为简化。该工作对异构集群下的 LLM serving 调度有较好的参考价值。
