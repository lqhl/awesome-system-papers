# CAGE: Curvature-Aware Gradient Estimation for Accurate Quantization-Aware Training

**作者**：Soroush Tabesh, Mher Safaryan, Andrei Panferov, Alexandra Volkova, Dan Alistarh

**链接**：https://proceedings.mlsys.org/paper_files/paper/2026

## 1. 背景

量化已成为大模型部署的标配技术,Llama、Gemma、GPT-OSS 等主流开源模型都发布了量化版本。但开源学术界的主要研究火力集中在 post-training quantization (PTQ)——先完整训练再离线量化,依赖一小批校准数据跑 GPTQ 之类的数值算法。

相比之下,quantization-aware training (QAT) 的进展慢得多。QAT 让模型在训练中就感知量化约束,理论上能取得更高精度,但计算成本更高。QAT 的长期 de facto 标准是 straight-through estimator (STE)——Hinton 2012 年提出、Bengio 2013 年形式化:前向走量化,反向假装量化算子的 Jacobian 是单位矩阵直接绕过不可导。PyTorch 等主流框架默认集成的就是这条路径。

围绕 STE,学界积累了 LSQ / LSQ+、AdaSTE、ReSTE、ProxQuant、PARQ、EWGS、Mirror Descent/MRF 等一大堆改进,手段无非三类:让量化参数 learnable、对梯度做 rescale、加 proximal/regularizer。问题在于这些方案多半是启发式,**几乎没有形式化的收敛保证**,并且在低比特 (W3A3、W2A2) 下精度和 FP16 仍有肉眼可见的差距。

---

## 2. 要解决的问题

作者想同时攻破两个痛点:

1. **理论层面的空白**:现有 QAT 算法的收敛分析(若有)在非凸设定下总会留下一个与量化误差成正比的**不消失项**——换句话说,就算训练步数 T → ∞,梯度范数也不会收敛到 0,这是因为目标 `∇f(Q(x)) = 0` 在一般情况下根本无解(量化后的点集离散,几乎肯定不能让连续函数的梯度恰好为 0)。
2. **实验层面的精度差距**:即便用上最新的 QuEST、LSQ+ 等 SOTA,W3A3、W2A2 预训练 Llama 相对 BF16 仍有明显 loss gap;QAT fine-tuning 也有一段无法闭合的精度下降。如何在不增加显著计算开销的前提下,把这段差距再砍一半?

具体的子问题:
- STE 的 error feedback 视角等价于一个"理想"的纠错循环,但只在 loss 是 isotropic quadratic 时才能完全纠错——真实 loss landscape 是 anisotropic 的,这个循环是失准的。能不能找到更好的纠错方式?
- 如何把量化约束显式纳入优化目标,并且还能证明某种形式的收敛?

---

## 3. 洞察与设计

**关键洞察**:由于量化算子 Q 不可逆,传统 QAT 目标 "找一个量化点 x* 使 ∇f(Q(x*)) = 0" 在一般非凸场景下无解。**应该换一个可达的最优性概念——Pareto 最优性**:同时考虑两个目标(最小化 loss、满足量化约束),迭代收敛到"任何小扰动都至少伤害其中一个目标"的平衡点。这个 Pareto 条件数学上表达为 `∇f(x*) + λ(x* - Q(x*)) = 0`,而最右边那项 `x - Q(x)` 正是量化误差,是**免费可得的信息**——不需要额外前向/反向。这才是让方法可实现、可收敛又有理论保证的核心前提。

基于这个洞察,CAGE 把标准 STE 梯度加上一个曲率感知的修正项:

$$g^{\text{CAGE}}_t = \widetilde{\nabla} f(x_t) + \lambda_t \cdot (x_t - Q(x_t))$$

这里 `x_t - Q(x_t)` 就是当前参数到它最近量化格点的距离。作者在平滑假设下证明它等价于某个 smooth regularizer φ 的梯度,因此整个迭代实际上在最小化正则化损失 `f(x) + λφ(x)`,而且不需要真的去算这个 φ。

两种 coupling 方式:
- **coupled correction**:把 `λe_t` 加到梯度上再喂给 optimizer。过 Adam 后会自然被 `1/(√v + ε)` 预条件,形成一个对角 Hessian 近似下的曲率感知修正。
- **decoupled correction**:让 Adam 先算完 update,再把 `αλe_t` 叠加到参数上,绕过预条件器。

作者选 decoupled 作为主力——理由:(1) 保留 Adam 原生行为,(2) Pareto 方向 `x - Q(x)` 不被 Adam 的预条件扭曲,低比特下更稳,(3) 避免不同量级项混合带来的数值问题。

**理论结果**(Theorem 1):SGD 基础上的 CAGE 在 `L_f` 平滑、梯度方差有界、Q 近似平滑的假设下,达到 $\mathcal{O}(1/\sqrt{T})$ 的遍历收敛到 λ-Pareto 最优点,**并且 upper bound 里没有不消失的量化误差常数项**——这是相对先前工作(Lin 2020、Chen 2021b、Panferov 2025b)的主要理论推进。

**与并发工作 LOTION 的关系**:LOTION (Kwun et al., 2025) 从 randomized rounding 平滑 loss 出发,用二阶展开得到 `f(x) + ½ Tr(H(x) cov[ε])` 作为 surrogate,再用 Gauss–Newton + 经验 Fisher + Adam statistics 做近似——最终形式和 CAGE 的 coupled 变体很像(差一个开根号)。CAGE 的优势:(1) 直接正则化训练动态而非 loss,不用对 regularizer 求导(否则要算三阶导);(2) LOTION 只支持 weight-only 量化、forward 仍要 FP,CAGE 支持 weights+activations 量化,可直接用低精度 GEMM kernel。

## 4. 实现细节

实现建立在 AdamW 之上(Algorithm 1,decoupled 版本):

```
每步 t:
  r_t ← t / T                                    # 训练进度
  λ_t ← warmup_schedule(r_t, s, λ)               # silence + linear ramp
  g_t ← STE 量化前向 + 反向                      # 常规梯度
  x_t ← (1 − αω) x_t                             # decoupled weight decay
  m_t, v_t ← Adam 动量/二阶矩更新
  x̃_{t+1} ← x_t − α m̂_t / (√v̂_t + ε)           # Adam 预条件后的更新
  e_t ← x_t − Q(x_t)                             # 量化误差,no grad
  x_{t+1} ← x̃_{t+1} − αλ_t e_t                  # CAGE 修正(decoupled)
```

核心要点:
- **Warmup 机制 (silence ratio s)**:训练开始前 sT 步完全不启用 CAGE 修正,之后线性 ramp 到 λ。类似 LR warmup,防止训练早期模型还没稳定时 Pareto 约束过早压制动态。作者实测 `s ∈ [0.8, 0.95]`、`λ ∈ [1, 2.5]` 对 AdamW 最稳。
- **量化器**:默认用 QuEST (Panferov 2025a) 的 row-wise Hadamard quantizer。先对 tensor 行做 Hadamard rotation `z = Hx`,再用 MSE 最优的 Gaussian clipping 因子 k_b 计算 scale,symmetric round,最后 `x̂ = Hᵀ ẑ`。反向用 QuEST 的 trust-masked STE。CAGE 本身是 quantizer-agnostic 的,作者特意声明可换任何量化器。
- **开销**:只多了一次参数减法 `e_t = x_t - Q(x_t)` 和一次加法;无需额外前向、反向或存 Hessian,完全是 element-wise 的 post-step。
- **官方实现**:https://github.com/IST-DASLab/CAGE

## 5. 实验结果

### 5.1 Synthetic

构造 `f(x) = ½ xᵀAx - bᵀx`,`κ(A) ∈ {1, 10, 100}`,4-bit 量化。对比 STE-SGD、STE-Adam、CAGE-Adam。结论:不同 condition number 下 CAGE 统计显著地把 final loss 打下来,且轨迹上 CAGE 最接近真实最优(Figure 1 + 2)。

### 5.2 QAT Fine-tuning (Llama-3.2-3B, MXFP4)

- Dataset: Tulu-SFT;量化格式: MXFP4 (4-bit FP);baseline: QuEST QAT recipe (Egiazarian 2025)。
- 评测: GSM8K (exact-match)、HellaSwag、WinoGrande。
- 结果: CAGE 相对 baseline **大约把量化精度损失砍半**(Figure 3)。有 Hadamard transform 和无 Hadamard 都有提升。

### 5.3 预训练 (Llama-style, C4 dataset)

Token budget `D = 100 × N`,模型 `N ∈ {30M, 50M, 100M, 200M, 430M, 800M}`,比特 `b ∈ {2, 3, 4}`,8×H100。每个点 3 seed 平均。

Table 1 — W4A4 final validation perplexity(越低越好):

| Method | 30M | 50M | 100M | 200M | 430M | 800M | eff(P) |
|---|---|---|---|---|---|---|---|
| CAGE + HT | 26.277 | 22.747 | 18.944 | 16.166 | 13.789 | 12.182 | 0.797 |
| QuEST + HT | 26.475 | 23.062 | 19.123 | 16.311 | 14.169 | 12.482 | 0.733 |
| CAGE (no HT) | 27.287 | 23.781 | 19.630 | 16.596 | 14.024 | 12.341 | 0.705 |
| QuEST (no HT) | 27.401 | 23.991 | 19.799 | 17.093 | 14.375 | 12.797 | 0.620 |
| BF16 (ref) | 24.715 | 21.491 | 17.923 | 15.422 | 13.176 | 11.698 | 1.0 |

核心观察:
- **CAGE 在所有模型尺寸、有/无 HT、所有精度下 Pareto 占优 QuEST**。
- 极强的 cross-precision 结论:**W3A3 CAGE 在 Pareto 前沿上优于 W4A4 QuEST**——先前最佳方法跑 4-bit 的 loss,CAGE 用 3-bit 就能打平甚至更好。
- 拟合 scaling law `L(N, D, P) = A/(N·eff(P))^α + B/D^β + E`,eff(P) 参数衡量"量化后等效模型容量"。CAGE 让 4-bit eff 提升 10%+,2-bit 提升 20%+。4-bit 是"最优"比特,但 3-bit CAGE 与之差距已很小。

### 5.4 Optimizer 普适性

50M OLMo2 模型、ClimbMix、D/N=100,比较 AdamW、Muon、Shampoo、SOAP,每个 optimizer 各跑 w/wo CAGE(固定 `s=0.9, λ=5`)。结果:**四种 optimizer 下 CAGE 都给出更低 val loss**(Figure 4),印证 optimizer-agnostic 特性。

### 5.5 vs LOTION

100M Llama,C4,W4A16(LOTION 只能 weight-only)。CAGE final loss 显著低于 LOTION,后者明显 plateau(Figure 8)。注意 LOTION 无官方实现,作者是自己复现的,并声明将在官方实现发布后复测。

### 5.6 Hyperparameter ablation

二维 sweep s × λ(Figure 9):`s ∈ [0.8, 0.95]`,`λ ∈ [1, 2.5]` 是稳定工作区。

## 6. 批判性分析

**定位清楚后,值得追问的几点**:

1. **理论声明与实验方法的不匹配**。Theorem 1 证的是 **SGD + CAGE** 的收敛,在 Adam(尤其 decoupled 版)下证明并不成立——作者也明确说 "coupled and decoupled coincide only for SGD"。但所有实际实验都跑在 AdamW / Muon / Shampoo 上。论文的理论贡献和实践贡献之间存在 gap,并未被充分讨论。

2. **与 LOTION 的比较不够公允**。LOTION 是并发工作,无官方实现,作者自行复现后宣称"CAGE 明显优于 LOTION"。这种情形下给出定性结论问题不大,但论文在 Related Work 和 Summary 处都已把 CAGE 定位为"泛化了 LOTION",然后又基于复现结果展示 CAGE 更优——这种"既框住对方、又打败对方"的叙事有 cherry-picking 风险。作者保留了重测声明,但 reviewer 视角应当 treat 该对比为**未决定论**。

3. **scaling law 的 eff(P) 拟合依据单一**。Table 1 里的 6 个模型尺寸 × 3 个 precision + BF16 只是一次 token-budget 下 (TPP=100) 的样本,联合拟合 `A, α, B, β, E` 共享而 eff(P) 分别拟合时,自由度相对数据点不算非常充裕;eff(P) 差 0.797 vs 0.733 这种绝对值差异,置信区间在论文正文里并未给出。

4. **改进幅度在不同实验之间风格不一**。Fine-tuning 报告"halves the quantization error"(定性),pretraining 报告 Table 1 (定量)。这两种衡量方式互不可比,"砍半"这个关键营销点其实只在 MXFP4 fine-tuning 一个场景严格可验证。

5. **作者没有 ablate 量化器**。所有主实验捆绑 QuEST + Hadamard。CAGE 声称 quantizer-agnostic,但只跑了一个量化器,至少应提供 1–2 个非 QuEST 量化器 (LSQ、AbsMax、per-channel affine) 的对照来支撑 agnostic 这个卖点。

6. **只报 final perplexity,不报 downstream benchmark**。Pretraining 模型(up to 800M)完全没跑 GSM8K/MMLU/HellaSwag 等下游 benchmark,只有 fine-tuning 实验做了这一步。至少 800M 规模下作者应当补上一轮 downstream eval,避免读者质疑"perplexity 下降是否转化为能力下降"。

7. **warmup/silence 机制缺少 principled 解释**。Algorithm 1 在前 sT 步完全关掉 CAGE,之后线性 ramp。作者解释是"防止早期 over-constrain",但理论分析里没给对应的时间变 λ 收敛证明。这暗示实践里仍有一定的"调参技巧"成分。

## 7. AI Infra / MLSys 视角

CAGE 对 MLSys / AI Infra 有不少可直接消化的价值。

**适合迁移的 insight**:

- **"免费信息 + 曲率感知"的套路**:CAGE 的核心工程 win 是用 `x - Q(x)` 这种**本就存在于优化循环里的量**作为方向信号,不需要额外计算。同类思路在其他压缩/加速场景都有迁移空间——比如 sparse training 里的 `x - top_k(x)`、low-rank training 里的 `x - UVᵀx` 残差、prune-during-train 里 mask 翻转的梯度、KV cache 压缩里的重建误差等都是类似结构。
- **Pareto 多目标视角取代"不可达的全局最优"**:这个哲学对很多 MLSys 问题有启示。比如 speculative decoding 的 draft/target 平衡、LLM serving 中 TTFT/throughput 的权衡、continuous batching 里 prefill/decode 资源抢占——都可以形式化为"找 Pareto 平衡点"而非强求某个最优解。
- **decoupled correction 作为 optimizer 外挂层**:CAGE 在 AdamW 之上做 post-step,既不破坏 Adam 内部状态又额外纠偏。类似的挂件模式对"已经 battle-tested 的 baseline + 少量新颖 correction"工程形态友好,方便 deployable。

**可跟进的研究方向**:

1. **极低精度预训练**:作者自己提到 future work 包括 ultra-low-bit regimes。W1A1、W1.58 (ternary)、4-bit 更极端的格式(MXFP4、NVFP4)下,CAGE 的 Pareto 正则是否依然有效?是否需要 regime-specific 的 λ schedule?
2. **CAGE × MoE**:MoE 模型权重大头是 expert FFN,且 experts 存在负载不均,当 expert 被激活频次少时 e_t 的统计性质会不同。可以研究 expert-wise λ、或者 activation-conditional 的动态 λ。
3. **CAGE × FSDP / ZeRO**:实现上 CAGE 多出的 `e_t = x_t - Q(x_t)` 只是 element-wise,对 sharded optimizer state 无额外通信开销——可以做 FSDP + QAT + CAGE 的一体化训练栈。
4. **CAGE × 动态 quantizer**:论文用 row-wise Hadamard + MSE clip 的 static schema。若 activation distribution 漂移剧烈(长上下文、multi-modal),动态 per-token / per-block 量化 + CAGE 如何调参?
5. **CAGE × post-training fine-tune of GPTQ/AWQ 模型**:目前 PTQ 模型用 CAGE 做 calibration 的 possibility 没被探索。PTQ 模型直接跑 CAGE-QAT 几十 step 是否能以极小成本恢复 perplexity 甚至超越原 FP baseline?
6. **理论拓展到 Adam / Muon**:把 Theorem 1 从 SGD 推广到真实使用的 adaptive optimizer。这是一个开放的凸优化 + 矩阵正则化问题,推完后会是很漂亮的 follow-up。

**小实验室的切入点**:这个方法最适合 600M 以下规模的 Llama-style pretraining 复现——8×A100 或 4×H100 一周内能跑完 Table 1 中 30M–200M 那几行,验证 `W3A3 CAGE > W4A4 QuEST` 是否 robust。若能同时跑通 downstream benchmark,就是一个完整的 follow-up paper 选题。

---

## 8. 总结

CAGE 把 QAT 从"启发式 STE 加各种 patch"推进到"Pareto 多目标视角 + 曲率感知正则化 + 可证明收敛"的新范式。核心是:把现成的量化误差 `x - Q(x)` 作为方向信号叠加到 gradient/update 上,不需要额外算力却能显著缩小低精度训练和 FP 训练的 gap——W3A3 能打平先前最佳方法的 W4A4。理论上给出非凸 smooth 场景下的 $\mathcal{O}(1/\sqrt{T})$ 收敛保证,补上了 QAT 领域长期的 formal 空白。实用上只在 AdamW 上做一次 element-wise 的 decoupled post-step,容易集成、optimizer-agnostic。适合场景是预训练 / 微调低比特 LLM;主要局限是理论(SGD)和实验(Adam 家族)之间有 gap,LOTION 对比不是独立实现,以及 pretraining 规模未做 downstream benchmark 验证。
