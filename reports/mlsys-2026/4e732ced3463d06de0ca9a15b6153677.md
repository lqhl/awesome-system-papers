# PRIVATAR: Enabling Privacy-Preserving Real-Time Multi-User VR Through Secure Offloading

## 1. 背景

多用户 VR(演唱会、球赛、协作办公等)的沉浸感依赖为每位用户实时渲染高保真数字分身(avatar)。当前主流做法是 Meta 等提出的 VAE(Variational Auto-Encoder)方案:发送端用 encoder 把高分辨率的 unwrapped facial texture(~1.3 MB)和 facial mesh(~1.3 MB)压缩成 256 维 latent code,接收端 decoder 解码。这样把单用户传输带宽从 1.25 Gbps 压到 0.49 Mbps。

但 VAE 把带宽瓶颈变成了**算力瓶颈**:接收端头显要为每个用户解码,单个 Meta Quest Pro(902 GFLOPS)在 60 FPS 下只撑得起约 2 人,而 decoder 中的 8 层 transposed convolution 占了 99.4% 的 FLOPs,几乎全部用来重建 texture。把计算卸载到本地网中算力更强但不可信的 PC/laptop 成了自然选择,但又引入了新问题:攻击者可在局域网或网关上窃听截获,从 latent code 反推人脸识别信息或表情/情绪/键击等隐私。

现有三类可证明的隐私方案都不够用:密码学方案(HE 慢 1000×,MPC 需 GB 级通信)、可信硬件(CPU TEE 吞吐不够)、信息论噪声(LDP 对高维数据加噪过大,毁掉 utility)。

---

## 2. 要解决的问题

在不可信的局域网设备上卸载 avatar 重建计算,同时做到:**i) 高保真 ii) 强隐私 iii) 能效友好 iv) 可扩展到多用户**,这四个目标过去不可兼得。更具体地,作者把失败原因归为两点:

- **整体数据卸载的两难**:要求整份卸载数据「足够模糊以保护隐私」又「足够精确以重建高质」是矛盾的。
- **各向同性噪声过度保守**:single-user 场景下没有 aggregation 可依赖,只剩 local DP。LDP 按最坏情况校准 sensitivity,对所有维度均匀加噪(isotropic noise),导致小值维度也被同样大的噪声淹没。实测把整份 latent 卸载到不可信 GPU + DP 噪声,重建 loss 暴增 105×,根本不可用。

## 3. 洞察与设计

**关键洞察 1 —— 频域能量极度不均衡**:对 unwrapped facial texture 做 block DCT(B=4)分解成 16 个频率分量,基频分量(component 0)独占 94.9% 的 L2 能量,其余 15 个分量加起来只有 ~5.1%(Fig. 4a、Fig. 6)。视觉上非基频分量都像噪声,单独看不出身份/表情。作者的推理:**既然大部分能量集中在基频,那么把基频留在头显内,只卸载低能量的非基频分量,天然就限制了不可信设备能看到的信息量,从而减少达到同等隐私所需的噪声**。

**关键洞察 2 —— 用户表情分布随时间缓慢漂移**:同一用户的表情分布在短时间窗内几乎静态 —— 训练集的 latent code 直方图与任意随机 2 秒片段(120 帧)的直方图几乎完全重合(Fig. 4b)。作者的推理:**既然每个用户的 latent 分布是已知且缓慢变化的各向异性(anisotropic)分布,就不必按最坏 sensitivity 加各向同性噪声,而可以按每维真实方差做各向异性噪声校准,大幅降低整体噪声能量**。

基于这两个洞察,PRIVATAR 的设计分两层(Fig. 5):

- **系统层 —— Horizontal Partitioning (HP)**:把 VAE 的 encoder/decoder 横向拆成两条并行路径。
  - Local path(绿色):facial mesh + 高能量基频分量,在头显本地加密处理。
  - Offloaded path(红色):低能量非基频分量加 DAMP 噪声后卸载给不可信 PC/laptop 解码,解码出的 noisy 非基频分量通过 WiFi-7 回传头显。
  - 头显在 Frequency Merger(❿)把本地高能量分量与回传的 noisy 低能量分量合并,再渲染成完整 avatar。
  - HP 同时做两件事:减少本地算力(卸载掉大部分 FLOPs)+ 限制不可信设备只看到不完整视图(empirical privacy)。

- **隐私层 —— Distribution-Aware Minimal Perturbation (DAMP)**:不用传统 DP 的 worst-case sensitivity,而是引入 MIT 的 PAC Privacy 框架(Xiao & Devadas 2023),让噪声协方差矩阵与 latent code 实际分布对齐。DAMP 持续追踪每个用户最新的 latent 协方差,按 SVD 分解出的每维方差 λ_i 按比例分配噪声 σ_i,从而在同等 MI 预算 ν 下,噪声的 L2 norm 最多比 isotropic DP 噪声小 **17.6×**(Fig. 7)。DAMP 把 HP 的经验隐私提升为**对任意攻击者的可证明隐私保证**(通过 PAC Privacy 的 posterior success rate 上界)。

两者组合后:HP 减少暴露信息量 → DAMP 所需噪声更少 → utility 损失更小;DAMP 同时把 HP 的经验保护升级为形式化保证。

## 4. 实现细节

- **VAE 基础**:沿用 Lombardi 2018 + Multiface 数据集的 DeepAppearanceVAE,输入 unwrapped texture(1024×1024×3)+ facial mesh(7306 vertex)。Latent code 维度 d=256。
- **频域分解**:B=4 的 block DCT,得到 16 个 256×256×3 的频率分量。每个分量是原 texture 的 1/16 大小,所以总数据量不变,但按分量可以灵活分配到两条 path。
- **分区策略**:默认 offload 14 个最低能量分量,保留 2 个最高能量分量(含基频)在本地。component 数 m ∈ [2, B²-2] 可调,用于 throughput/loss 的 Pareto 搜索。
- **本地 VAE 架构缩减**:由于输入降到 1/B 分辨率,local encoder/decoder 都削掉 log₂(B)=2 层,单分量重建成本约为原始 VAE 的 1/B² = 1/16。
- **DAMP 噪声计算(Appendix B)**:
  1. 对 profiled offloaded latent 的协方差矩阵 Σ_F(X) 做 SVD: U·s·Uᵀ。
  2. 给定 MI 预算 ν(对应 t-PSR 上界,如 ν=0.1 对应 t-PSR=9%),按 σ_i = √λ_i · Σ√λ_j / (2ν) 求最小噪声特征值。
  3. 从 N(0, U·σ·Uᵀ) 采噪声注入 latent code 后卸载。
- **分布更新**:用户的 latent 协方差存在头显本地,**永不离开设备**,用户每产生新 latent 都在线增量更新协方差。
- **通信**:local path 的 latent 用共享密钥加密(Shamir 秘密共享 + AES-GCM);offloaded path 不加密 latent,依赖 DAMP 噪声保证隐私,但对回传的 noisy reconstructed components 走 WiFi-7(≤20 Gbps)。
- **代码规模**:6 个模型变体 + experiment scripts,开源在 https://github.com/georgia-tech-synergy-lab/Privatar,DOI 10.5281/zenodo.19443137。

## 5. 实验结果

**硬件**:Meta Quest Pro(902 GFLOPS GPU)作为头显,RTX 5090(non-TEE)或 AMD Threadripper 7985WX(带 SME 的 CPU TEE)作为 offload host,WiFi-7 互联。额外在 Quest 3(3709 GOPS,4.1× 于 Quest Pro)上复测。

**数据集**:Multiface(13 identities × 65–143 expressions × 40 views,~1.7M 帧,~15 TB)。

**主指标**:Normalized loss(相对 baseline L0=0.072 的 MSE)、#Users(60 FPS 下可支持用户数)、e-PSR(最大经验 posterior success rate,两类攻击中更强者)、能耗。

**PRIVATAR vs SotAs(Quest Pro,Tab. 2)**:

| 技术 | Loss (↓) | #Users (↑) | e-PSR |
|---|---|---|---|
| Baseline(本地完整重建) | 1× | 1× | 1.54%(随机猜) |
| 10% 通道剪枝 | 1.25× | 1.15× | 1.54% |
| 8-bit 权重量化 | 1.004× | 1.04× | 1.54% |
| CPU + SME(TEE) | 1× | 1.79× | 1.54% |
| Fully Offload + Isotropic DP | 105× | 2.3× | 85.6% |
| **PRIVATAR(HP + DAMP)** | **1.08×** | **2.37×** | **1.54%** |

**消融(Fig. 10)**:

- 无噪声时,HP 本身只带来 5.7%–6.4% 的 loss 增加(LPIPS 只涨 0.72%,肉眼几乎不可辨)。
- m 越大 → 本地延迟越低、offload 通信延迟越高,两者此消彼长,m=14 是 Pareto 点;更大 m 会被通信拖垮。
- DAMP 相比 isotropic DP,在 t-PSR=40%/9%/3.5% 下噪声 L2 norm 分别减少 **17.6× / 4.1× / 1.1×**(噪声越大增益越小,因为分布对降噪的贡献被淹没)。
- 只要基频留在本地,各种 (m, ν) 组合下 e-PSR 都停在 random-guess 1.54%,说明 HP 对经验攻击稳健。
- 最终推荐配置:m=14 + ν=0.1(t-PSR=9%),loss 增加 8.3%,e-PSR 保持随机猜水平。

**能耗**:+9% 总能耗(compute 按 32 GOP/s/W、通信按 13.94 nJ/bit 估算),换 2.37× 用户 → 2.17× users/Watt。

**攻击稳健性**:
- Empirical attacker(匹配频率参考)原本在 Fully Offload + 低噪声下能达到 86.5% PSR,加 HP + DAMP 后跌回 1.54%。
- NN-based attacker(3 层 FC,256→128→66)在 HP + DAMP 下也只能到 1.54%,低于 prior rate。

**Quest 3 加测**:计算更强后本地基线已能支持 10.6 人,PRIVATAR 仍能再加 1.34× 并保持 4.6% loss,此时瓶颈从本地算力转移到 PC→头显通信带宽。

## 6. 批判性分析

- **威胁模型对「不可信设备」的假设过于简化**:论文假定攻击者是 honest-but-curious(会窃听、遵守协议)且仅观察卸载数据。但实际局域网设备可能**篡改**回传的 noisy components(integrity 攻击),从而污染最终 avatar 渲染 —— PRIVATAR 没有对抗这种主动攻击的验证机制(仅提了 §4.1 一句「GCM 提供 authentication」,但那是针对 local path 的加密通道,offloaded path 的 noisy 回传数据并未做完整性校验)。
- **PAC Privacy 的安全保证依赖「adversary knows D」**:PAC Privacy 的形式化保证假定攻击者知道用户真实分布 D,现实中攻击者可能持有**更强的侧信道**(比如之前几分钟的历史 latent 已经泄露过未加噪版本),此时 DAMP 用「slowly drifting distribution」作为 anchor 反而可能被用来反推当前 expression,论文没分析这种自适应攻击。
- **「base component 留本地就安全」的经验结论外推风险**:Fig. 10d 显示 e-PSR 在所有测试配置下都是 1.54%,但两个攻击者都比较弱 —— empirical attacker 是基于参考匹配的简单近邻,NN attacker 只是 3 层 FC。更强的 diffusion-based reconstruction 攻击或跨 frame 时序攻击(利用连续帧的 latent 相关性)可能突破这个下界。
- **Loss 的评估维度过窄**:报告用 MSE 和 LPIPS,但 avatar 重建的真正质量指标是**时序稳定性**和**表情保真度**(嘴角上扬、眨眼是否保留)。5.7% MSE 看起来小,但如果分布在情绪相关的高频分量里,可能造成表情漂移,而论文提供的是静帧 MSE。
- **用户分布的隐私假设**:DAMP 用每个用户的历史 latent 协方差加噪。这意味着系统要**长期持有用户表情统计**。虽然论文声称协方差「永不离开头显」,但长期积累的分布本身就是身份指纹(加入同态学到的 population distribution 后可做 linkage attack)。论文对 metadata 隐私分析不足。
- **实验只跑了 Multiface 单一数据集**:13 个 identity 的训练集对 DAMP 的 distribution 估计足够,但无法验证在 diversity 更大的群体(肤色/年龄/表情范围)上能否保持同样的频域能量集中性(94.9% 基频)。不同人群可能有不同的频域特征分布。
- **与 TEE 方案的对比不完全公平**:文中 CPU TEE 用的是 AMD 9950X3D 的 SME,而 GPU TEE(如 NVIDIA Hopper 的 CC)并未评估。作者的理由是「RTX 5090 没有 TEE」,但 H100/H200 都有 Confidential Computing,完整对比应该包含 GPU TEE —— 否则 PRIVATAR 1.32× 领先 CPU TEE 的结论不能外推到整个「TEE 方案」。
- **「加密通道开销可忽略」一笔带过**:local path 声称用 Shamir 秘密共享 + runtime GCM,但未给出具体延迟 —— 若密钥协商在每新用户接入时都要做,多用户 join/leave 频繁时这部分 overhead 可能不可忽略。

## 7. AI Infra / MLSys 视角

这篇论文虽然表面是 VR avatar 系统,但它抽象出的方法论对 **AI Infra 中"隐私/效率"权衡的计算卸载**有很强的借鉴意义:

- **LLM inference 的 KV cache / embedding 卸载**:大模型推理也面临「数据量大、算力/显存不足、但 embedding/KV 里藏着用户 prompt」的相同结构。PRIVATAR 的核心思路 —— 「做一个与任务相关的分解(这里是 DCT),把信息量最大的分量留本地、低信息量分量卸载」—— 可以迁移到 prompt embedding 的 PCA 分解卸载、KV cache 的 head-wise 分区卸载。future work:对 attention head 做 SVD 能否找出类似的「高能量 head 留本地、低能量 head 卸载」划分?
- **PAC Privacy 在 MLSys 场景的落地**:DP 的 worst-case sensitivity 在大模型训练(DP-SGD)中一直是 utility 瓶颈,PRIVATAR 是 PAC Privacy 第一个在时序 facial 数据上的工程落地。对 DP-SGD、联邦学习(FedAvg + LDP)做「distribution-aware noise」替换,理论上也能拿到同量级的噪声缩减。具体研究问题:能否在 LoRA 微调的 gradient 分布上做在线 PAC noise calibration,把 per-example clipping 的 utility 损失从 DP 的 worst-case 改到 PAC 的 instance-optimal?
- **异构 TEE/non-TEE 混合调度**:PRIVATAR 事实上做的是「敏感子集在 TEE(头显相当于小 TEE)+ 非敏感子集在非 TEE 设备」的分层调度。这是未来 GPU TEE(H100 CC、Intel TDX)真正 GA 后的通用模式 —— 不是所有 token/layer 都要进 TEE,而是按敏感度动态划分。PRIVATAR 给出的「frequency-domain variance 作为 sensitivity proxy」是一个可量化的划分 heuristic,对 LLM 可以启发做「token attention weight / gradient magnitude 作为 sensitivity proxy」。
- **对 reconfigurable accelerator 的启发**:作者自己在结尾提到 MiniSA/FEATHER 等 reconfigurable 加速器能吃下 PRIVATAR 的细粒度分区。这映射到 AI infra 的具体问题是:如果 accelerator 能按层/按 head 快速 reshape dataflow,就能承载「部分卸载」的不规则 workload shape —— 对 dense LLM 做 expert-wise 或 head-wise 的计算-通信 co-design,是一个 concrete 的 follow-up 方向。
- **可值得跟进的切入点**:最有价值的是把 DAMP 的 per-user distribution tracking 推广到 **LLM 推理侧的 per-prompt / per-session 分布在线追踪** —— 对单个会话的 prompt embedding 做滑动窗口协方差估计,实时校准噪声以保护 prompt 隐私,特别适合 B2B LLM API(企业租户不信任模型提供商)。目前的 privacy-preserving LLM inference 要么依赖 HE(慢 3 个数量级)要么依赖 fully TEE(受限于 GPU 显存),PAC-based distribution-aware noise injection 是一个实用的第三条路。

## 8. 总结

PRIVATAR 是第一个把「secure computation offloading」从密码学/TEE 重新框定为「representation decision + anisotropic noise calibration」的 VR 系统:用 block DCT 把人脸 texture 拆成 16 个频率分量,基于能量分布把 94.9% 能量的基频留在头显、剩余分量卸载到不可信设备;再用 PAC Privacy 按用户 latent 真实分布做各向异性噪声(最多比 LDP 小 17.6×),在不可信通路上提供形式化隐私保证。在 Meta Quest Pro 上 2.37× 用户、+9% 能耗、8.3% loss 增加、e-PSR 保持随机猜水平。主要局限是威胁模型偏 honest-but-curious、缺少时序/自适应攻击分析,且仅在 Multiface 单一数据集上评估。核心方法论(task-aware 分解 + distribution-aware PAC 噪声)对 LLM inference 隐私、联邦学习、异构 TEE 调度都有迁移价值。
