# MixLLM: LLM Quantization with Global Mixed-precision between Output-features and Highly-efficient System Design

**作者**：Zhen Zheng, Xiaonan Song, Chuanjie Liu (Microsoft)

---

## 一、背景

LLM 量化是压缩模型、降低部署成本的核心手段。现有量化方案在**精度、内存消耗、系统效率**这三角关系中难以兼顾：

- **Weight-only 量化**（如 GPTQ、AWQ）：4-bit 量化在高信息密度模型（如 Llama 3）上精度下降明显，且在大 batch 场景下因 dequantization 开销导致系统效率低于 FP16。
- **Weight-activation 量化**（如 SmoothQuant、QoQ）：activation 难以量化，4-bit activation 精度损失大；asymmetric 量化和 group-wise 量化给 GPU kernel 设计带来困难，难以高效利用 Tensor Core。
- **Outlier 分离 / 混合精度**（如 SpQR、Atom）：非结构化 outlier 导致稀疏计算效率低；Atom 在 input feature 维度做混合精度，受限于 tiling 对齐约束且精度仍不理想。

随着 continuous batching 和 chunked-prefill 等推理优化推动 MatMul 向 compute-bound 转变，同时降低计算量和内存的需求愈发迫切。

---

## 二、要解决的问题

1. **精度与内存的矛盾**：4-bit 量化内存省但精度差，5-bit 精度好但缺乏硬件支持，需要在 4-bit 基础上用最少额外 bit 恢复精度。
2. **Salience 识别的局限**：现有方法按 layer 局部确定 outlier 比例（固定阈值/比例），忽略了不同 layer 对模型最终 loss 的贡献差异。
3. **系统效率瓶颈**：asymmetric group-wise 量化无法直接使用 int8 Tensor Core；integer-to-float (I2F) 转换指令昂贵（GPU 上 I2F 比普通计算慢很多）；现有系统缺乏良好的 software pipeline 来重叠 dequantization 与 MatMul 计算。

---

## 三、洞察与设计

**关键洞察**：不同 output feature（output channel）对模型最终 loss 的贡献差异巨大，且这种差异在全局视角下比 layer 局部视角更显著——某些 layer（如 v_proj、down_proj）集中了大量高 salience channel，而其他 layer 几乎没有。因此，在 output feature 维度做全局混合精度分配，比按 layer 均匀分配更高效。

基于此洞察，MixLLM 的核心设计包括：

1. **Output feature 维度混合精度**：将权重按 output channel 分为 8-bit（高 salience）和 4-bit（低 salience）两组。不同 output feature 的 MatMul 计算天然解耦（disjoint sub-problems），可以并行执行，避免了 input feature 混合精度的 tiling 对齐约束。

2. **全局 salience 搜索**：用 Taylor 展开估计每个 output channel 被量化后对模型最终 loss 的影响（Eq.4），利用 Fisher 信息矩阵近似 Hessian，保留一阶项（因为对预训练良好的模型，一阶项可能比二阶项更显著）。全局排序后，取 top-N 分配 8-bit。单次搜索即可，无需迭代。

3. **算法-系统协同的量化配置**：
   - Activation 用 8-bit symmetric group-wise（精度足够，且 MatMul 主要受 weight tensor 大小约束）
   - Weight 4-bit 部分用 asymmetric group-wise（精度更好），8-bit 部分用 symmetric
   - 这个配置是精度和系统效率的 sweet spot

## 四、实现细节

### Two-step Dequantization

解决 asymmetric W4A8 无法直接用 int8 Tensor Core 的问题：
1. 先将 uint4 权重部分 dequantize 为 `(W_q - z)`（int8 范围内，无溢出）
2. 用 int8 Tensor Core 计算 `A_q × (W_q - z)`
3. 最后乘以 `s_a × s_w` 完成 dequantization

### Fast I2F 转换

利用 IEEE 754 浮点数与整数在特定区间内的二进制表示相同的性质，将昂贵的 I2F 指令替换为两次 add/sub：
- 加 bias_int（0x4b400000）使整数落入安全区间
- 减 bias_fp（同一二进制对应的浮点值）恢复浮点值
- 进一步将整数加法融入 Tensor Core MMA 指令的 accumulator 初始化，最终 I2F 退化为一次浮点减法
- 对 512/4096/4096 MatMul 带来 >20 TOPS 性能提升

### Software Pipeline

引入三级 tiling（warp tile、block tile、quantization group tile），使用双输出缓冲区（per-group buffer + global buffer）。Pipeline 重叠：
- Global memory → Shared memory（G2S）
- Shared memory → Register（S2R）
- SIMT Core dequantization 与 Tensor Core MMA 并行
- 权重预打包（ahead-of-time prepack）避免运行时 permutation

### 并行执行

两个 bit-width 的子问题通过 CUDA Graph 并行执行，输出通过 fused scatter epilogue 写入同一 tensor 的不同 channel 位置。

### 搜索开销

7B/8B 模型搜索约 7 分钟（单 A100），70B 模型约 55 分钟（4×A100），一次性开销。

## 六、批判性分析

1. **系统实验仅限单层 MatMul**：性能评估只测了单个 linear layer 的 kernel 速度（Fig.5），缺少端到端推理的 latency 和 throughput 数据。实际部署中，两个子问题的 CUDA Graph 并行执行、fused scatter 的开销、以及与 attention/其他算子的交互都可能影响最终表现。

2. **仅在 A100 上验证**：所有系统实验都在 A100 上完成。A100 的 int8 Tensor Core 特性（如 throughput 比例、shared memory 大小）与 H100/H200/B200 差异显著，论文声称"基本原理通用"但未提供跨硬件验证。

3. **搜索开销的可扩展性存疑**：70B 模型搜索需 55 分钟（4×A100），对更大模型（如 405B）的开销未讨论。虽然是一次性开销，但校准数据集的选择对 salience 排序的鲁棒性也缺乏分析。

4. **10% 8-bit 的选择缺乏理论依据**：论文展示了 0%/10%/20%/50%/100% 的结果，但为什么 10% 是 sweet spot 主要靠经验观察。对于不同模型架构或规模，这个比例是否需要调整未充分讨论。

5. **Ablation 呈现方式有偏**：Fig.6 的 ablation 从极差的 W4A4 RTN per-channel symmetric 开始逐步叠加优化，使每步改进看起来都很大。但多个决策（如 8-bit activation、asymmetric weight、group-wise）是已知的良好实践，并非 MixLLM 的独特贡献。真正属于 MixLLM 的增量（全局 10% 8-bit + Fisher salience）在 ablation 中仅贡献了从 6.830 → 6.489 的改进。

6. **与 FP6 量化方案的对比缺失**：ZeroQuant(4+2) 和 Quant-LLM 探索了 FP6 量化，平均 bit-width 与 W4.4A8 接近，但论文仅引用而未直接对比。

## 七、AI Infra / MLSys 视角

1. **Output feature 维度混合精度是一个值得深入的方向**：与 input feature 混合精度相比，output feature 天然解耦，对 GPU kernel 设计更友好。这个思路可以推广到 KV cache 量化（不同 head 的 salience 不同）和 LoRA 微调（不同 output channel 的重要性指导 rank 分配）。

2. **全局 salience 搜索的启发**：layer 级别的局部决策在很多 AI Infra 场景中都是次优的——如分布式训练中的 layer-wise 通信压缩、pipeline 并行中的 stage 划分。MixLLM 的全局视角（考虑各 layer 对最终 loss 的贡献差异）值得借鉴。

3. **Fast I2F 技巧的通用性**：利用 IEEE 754 浮点二进制特性将 I2F 融入 MMA accumulator，这个技巧适用于所有需要 integer Tensor Core + float post-processing 的场景，包括量化 attention、integer 激活的 MLP 等。

4. **可操作的 follow-up 方向**：
   - 将 output feature 混合精度扩展到 prefill 阶段的 KV cache 量化，按 head 或 channel 的全局 salience 分配精度
   - 在 H100/B200 的 FP8 Tensor Core 上探索 FP8/FP4 混合精度的类似设计
   - 动态 salience：根据输入特征在运行时调整混合精度比例，而非静态搜索

---

## 八、总结

MixLLM 提出了 output feature 维度的全局混合精度量化方案，通过 Taylor 展开估计每个 output channel 对模型最终 loss 的全局 salience，将 top 10% 分配 8-bit、其余 4-bit。算法-系统协同设计（two-step dequantization、fast I2F、software pipeline）使其在 A100 上同时实现 SOTA 精度（W4.4A8 PPL 增量 <0.2 vs. SOTA 的 ~0.5）和高系统效率（相比 FP16 平均 1.88x 加速）。主要局限是缺少端到端推理评估和跨硬件验证，且 10% 8-bit 比例的选择偏经验化。适用于对量化精度敏感的 LLM 推理部署场景。
