# awesome-system-papers

个人学术论文收藏库，整理和下载系统领域顶级会议的论文 PDF，供学习研究使用。

## 内容

- **论文 PDF**：系统领域顶级会议的论文，按 Topic 或会议-年份目录存放于 `papers/` 下
- **阅读报告**：每篇论文的笔记与总结，按会议或 Topic 分类
- **自动下载**：脚本支持从各会议官网自动下载论文 PDF
